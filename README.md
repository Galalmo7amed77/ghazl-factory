# نظام إدارة مصنع الغزل

## محتويات المستودع
- `index.html`: صفحة النظام الرئيسية المطلوبة لتشغيل GitHub Pages.
- `.nojekyll`: ملف إعداد بسيط لـ GitHub Pages.

## النشر على GitHub Pages
1. أنشئ مستودعًا باسم `ghazl-factory`.
2. ارفع محتويات هذا المجلد إلى جذر المستودع، وليس المجلد نفسه.
3. من المستودع افتح Settings ثم Pages.
4. اختر Deploy from a branch، ثم `main` و`/(root)`، واضغط Save.
5. انتظر حتى يظهر رابط الموقع في صفحة Pages.

## أول تشغيل
1. افتح رابط الموقع.
2. أدخل رابط مشروع Supabase الخاص بمصنع الغزل.
3. أدخل **Publishable key** أو مفتاح `anon` العام القديم فقط.
4. لا تضع أبدًا `service_role` أو أي Secret key داخل الموقع.
5. سجّل الدخول بحساب الإدارة أو المشرف.

## ملاحظات
- بيانات العمال والحضور محفوظة في Supabase، وليست داخل ملفات الموقع.
- مفتاح النشر العام يُحفظ محليًا في المتصفح الذي أدخلته منه؛ قد تحتاج لإدخاله على جهاز أو متصفح آخر.
- يعتمد فصل الصلاحيات على سياسات RLS في Supabase التي تم إعدادها مسبقًا.
- هذه النسخة تشمل إدارة العمال وتسجيل الحضور والانصراف. لم تُضف بعد كشوف الرواتب أو تسجيل الخامات والإنتاج.
